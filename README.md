# Public Domain Playing Cards

[![Preview](https://github.com/AustinGabriel/Public-Domain-and-CC0-Playing-Cards/raw/f433681a3fe42708105a73def58f1105f7e92bff/PREVIEW%201.png)](https://github.com/AustinGabriel/Public-Domain-and-CC0-Playing-Cards/blob/f433681a3fe42708105a73def58f1105f7e92bff/PREVIEW%201.png)

A complete, standard poker-sized 54-card deck (52 cards + 2 jokers), built entirely from public domain / CC0 sources and released for free, unrestricted use — commercial physical card printing, digital games, or anything else.

Every card comes as both **SVG** (vector, infinitely scalable) and **PNG** (raster), so you can drop them straight into a game engine, a print-on-demand template, or a design tool with no conversion step required.

## What's included

- All 52 standard cards across four suits (Spades, Hearts, Clubs, Diamonds), Ace through King
- 2 Jokers (black and red)
- 2 card backs (blue and red)
- Every card provided as both an SVG and a PNG
- Ornate, court-style face cards (Jack, Queen, King) and a decorative Ace of Spades

## Usage

Grab what you need from the [`svg cards`](./svg%20cards) or [`png cards`](./png%20cards) folders. Files are named by suit and rank, e.g.:

- `ace of spades.svg`
- `king of hearts.png`
- `red joker.svg`
- `card back blue.png`

Common uses:

- Physical / print-on-demand card decks
- Tabletop or digital card games
- Prototyping and game jams
- Design assets for card-based UIs
